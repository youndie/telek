val Message.telekChatId: Long

ktgbotapi models ids as value classes (ChatId/RawChatId, MessageId); telek keys everything by a plain Long. These adapters are the whole of that translation — they're public so a bot wiring its own update handling (webhooks, a custom FlowsUpdatesFilter) can reuse them instead of going through connect.

fun ContentMessage<LocationContent>.asTelekInput(): Location

Latitude and longitude only, and a live location collapses to the point it was at. telek has no notion of a location that keeps moving — a wizard step that asks "where are you" is answered by a point, and anything richer is a bot's own io.github.youndie.telek.Input.

fun ContentMessage<PhotoContent>.asTelekInput(): Photo

Carries content.media — the size ktgbotapi designates for the collection — and not a pick of telek's own out of mediaCollection. telek does not model photo sizes: a wizard step keeps the photo, and a bot that wants a specific size asks the transport for it.
